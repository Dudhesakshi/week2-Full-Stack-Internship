# TechNova Solutions

A modern, responsive company website developed as part of the WeIntern Full Stack Internship Week 2 Task 1.

## 🚀 Project Overview

TechNova Solutions is a fictional technology company website designed to showcase digital services and provide a professional online presence.

The website includes multiple responsive pages with modern UI, smooth navigation, interactive elements, and a clean blue-themed design.

## 📄 Pages

- **Home** – Introduction, company highlights, services preview, and call-to-action.
- **About Us** – Company story, mission, vision, and key strengths.
- **Services** – Overview of technology and digital services.
- **Contact Us** – Contact information and inquiry form.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern blue-themed user interface
- Multi-page website navigation
- Mobile navigation menu
- Smooth scrolling and scroll animations
- Animated statistics
- Interactive contact form
- Reusable CSS and JavaScript
- Clean and structured code
